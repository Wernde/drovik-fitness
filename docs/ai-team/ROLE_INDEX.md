# Role Index

Use the smallest set of roles that covers the work. The Lead Engineer remains responsible for coordination and integration.

| Need | Primary role | Common supporting roles |
| --- | --- | --- |
| Scope, requirements, roadmap | Product Manager | UX Architect, Blueprint Editor |
| User journey or navigation | UX Architect | Responsive/PWA Experience, Accessibility |
| Visual redesign | UI and Visual Designer | Design-System Custodian, Responsive/PWA Experience |
| React or TypeScript implementation | React and TypeScript Engineer | Integration Engineer, QA Test Designer |
| Dexie schema or offline writes | Local-First Data Engineer | Data Integrity Reviewer, Sync Engineer |
| Supabase, auth, RLS, or sync | Supabase and Sync Engineer | Security Reviewer, Data Integrity Reviewer |
| Installation, caching, offline launch | PWA Reliability Engineer | Quality/Device Reviewer, Release Gatekeeper |
| Slow loading or rendering | Performance Engineer | React Engineer, Asset Specialist |
| Cross-subsystem change | Integration Engineer | Relevant subsystem owners |
| Test strategy or regression | QA Test Designer | Mobile/Cross-Device Tester, Release Gatekeeper |
| Security or privacy | Security and Privacy Reviewer | Sync Engineer, Dependency Reviewer |
| Setup or troubleshooting instructions | Technical Writer | Architecture Recorder |
| Current/future product documentation | Product Blueprint Editor | Product Manager |
| Architecture rationale | Architecture Decision Recorder | Lead Engineer, Integration Engineer |
| Release summary | Changelog and Release Notes Editor | Release Gatekeeper |
| Exercise catalogue quality | Exercise Data Curator | Fitness Domain Reviewer |
| Charts and progress interpretation | Data Visualisation Specialist | Fitness Domain Reviewer |
| Backup/import recovery | Backup and Recovery Specialist | Data Integrity Reviewer |
| Icons, images, and app assets | Icon and Asset Specialist | UI Designer, PWA Reliability Engineer |
| Diagnostics and error reporting | Observability Specialist | Security Reviewer |
| New package proposal | Dependency Reviewer | Performance and Security Reviewers |
| Australian English interface copy | Australian English Copy Editor | Technical Writer |

## Weekly lightweight crew

The weekly review uses five functions, which may be performed by a smaller number of agents:

1. Weekly Coordinator
2. Product and UX Reviewer
3. Reliability and Data Reviewer
4. Quality and Device Reviewer
5. Documentation and Release Reviewer

Their instructions and report format are in [WEEKLY_REVIEW.md](WEEKLY_REVIEW.md).
