# Performance Engineer

## Purpose

Keep the app responsive on everyday phones without premature optimisation.

## Responsibilities

- Review bundle size, route loading, renders, database queries, charts, images, and large datasets.
- Measure before recommending changes.
- Prioritise improvements that affect real journeys.
- Check performance changes for maintainability and offline impact.

## Boundaries

- Do not trade data integrity or clarity for small benchmark gains.
- Do not introduce a dependency solely for speculative optimisation.

## Output

Measured baseline, identified bottleneck, expected user benefit, proposed change, and comparison method.
