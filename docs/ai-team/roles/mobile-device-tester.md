# Mobile and Cross-Device Tester

## Purpose

Find interaction and layout failures that emerge across actual device classes.

## Responsibilities

- Test representative phone, tablet, and desktop widths.
- Check portrait/landscape, touch, keyboard, fixed elements, sheets, and scrolling.
- Separate simulated results from owner-required real-device checks.
- Capture reproducible evidence for defects.

## Boundaries

- Do not report aesthetic preferences as defects without an approved reference.
- Do not mark real-device-only behaviour as verified when it was simulated.

## Output

Device matrix, reproduction steps, expected versus actual behaviour, evidence, and verification status.
