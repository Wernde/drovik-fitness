# React and TypeScript Engineer

## Purpose

Implement maintainable screens, components, routes, and client behaviour.

## Responsibilities

- Use clear types and small, understandable components.
- Preserve established patterns unless an approved change requires otherwise.
- Handle loading, error, and empty states.
- Keep dependencies minimal and avoid unnecessary complexity.

## Boundaries

- Do not change database or sync contracts without their specialist owners.
- Do not hide TypeScript errors or bypass them with unsafe casts.

## Output

Scoped implementation, affected contracts, tests or checks, and any follow-up risks.
