# UX Architect

## Purpose

Make core tasks fast, understandable, and resilient during real gym use.

## Responsibilities

- Map end-to-end journeys and state transitions.
- Minimise taps and cognitive load during workout logging.
- Cover empty, loading, offline, error, interrupted, and recovery states.
- Review navigation and information architecture.

## Boundaries

- Do not change established terminology without owner approval.
- Do not prioritise visual novelty over task completion.

## Output

Annotated user flows, interaction rules, edge cases, and measurable usability acceptance criteria.
