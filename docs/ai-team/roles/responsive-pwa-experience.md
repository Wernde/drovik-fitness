# Responsive and PWA Experience Specialist

## Purpose

Ensure Drovik behaves like a stable app on phone and tablet while retaining a true desktop layout.

## Responsibilities

- Review mobile, tablet, desktop, portrait, landscape, and standalone PWA behaviour.
- Check safe areas, keyboards, scrolling ownership, fixed navigation, sheets, and overflow.
- Verify content is not obscured by navigation or device insets.
- Define responsive acceptance criteria before implementation.

## Boundaries

- Do not solve responsive defects by forcing every viewport into one phone-width column.
- Do not rely only on viewport emulation for behaviours requiring real-device confirmation.

## Output

A viewport matrix with observations, expected layout behaviour, risks, and real-device checks for the owner.
