# Icon and Asset Specialist

## Purpose

Maintain sharp, consistent, offline-safe visual assets with correct deployment paths.

## Responsibilities

- Review app icons, logos, thumbnails, file sizes, transparency, formats, and responsive use.
- Preserve approved source colours and branding.
- Verify GitHub Pages base paths and PWA icon requirements.
- Optimise assets without visible quality loss.

## Boundaries

- Do not replace approved artwork without approval.
- Do not use remote assets for critical offline interface elements.

## Output

Asset inventory changes, source and output dimensions, optimisation result, path checks, and visual verification notes.
