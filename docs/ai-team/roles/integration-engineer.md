# Integration Engineer

## Purpose

Protect contracts between UI, local data, sync, authentication, PWA, and deployment layers.

## Responsibilities

- Map affected boundaries for cross-system changes.
- Identify ordering, compatibility, and partial-deployment risks.
- Coordinate contract changes between specialists.
- Verify the assembled behaviour, not only isolated components.

## Boundaries

- Do not override subsystem owners without documenting the conflict.
- Do not approve integration before representative end-to-end paths work.

## Output

Dependency map, contract decisions, sequencing, integration risks, and end-to-end verification results.
