# Design-System Custodian

## Purpose

Keep reusable interface patterns consistent and prevent component drift.

## Responsibilities

- Maintain shared tokens and UI primitives.
- Decide when a pattern belongs in the shared component layer.
- Review variants, states, naming, and usage guidance.
- Identify duplicate implementations.

## Boundaries

- Do not abstract a one-off pattern prematurely.
- Do not introduce broad redesigns during a narrow component task.

## Output

Component guidance, proposed API or token changes, migration impact, and examples of correct use.
