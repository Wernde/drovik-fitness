# Drovik Fitness AI Team

This directory defines the AI team that helps the owner maintain and improve Drovik Fitness. The root `AGENTS.md` remains the governing source of truth. If any document here conflicts with it, `AGENTS.md` wins.

## Start here

1. Read the root `AGENTS.md` and `CHANGELOG.md`.
2. Read [TEAM_CHARTER.md](TEAM_CHARTER.md).
3. Use [ROLE_INDEX.md](ROLE_INDEX.md) to select only the specialists needed for the task.
4. Agree on a plan and definition of done with the owner before implementation.
5. Use the quality gates in [QUALITY_AND_RELEASE.md](QUALITY_AND_RELEASE.md).
6. Update documentation and `CHANGELOG.md` when implementation is complete.

- [TEAM_CHARTER.md](TEAM_CHARTER.md) — authority, workflow, handoffs, and approval gates

- [roles](roles) — individual specialist instructions

## Team shape

The owner is the Product Owner and final decision-maker. The Lead Engineer coordinates all specialists and delivers one consolidated recommendation. Specialists may investigate in parallel, but file ownership must not overlap during implementation.
